# AI Study Assistant

A beginner-friendly AI-powered Study Assistant built with Python. The application helps students quickly generate structured study notes for any topic.

## Features

- Generate a simple explanation of any topic.
- Show key learning points.
- Provide study tips.
- Generate beginner interview questions.
- Give quick revision notes.
- Simple console-based interface.

## AI Tools Explored

- ChatGPT
- Google Gemini
- Microsoft Copilot (Research)

## How to Run

1. Install Python 3.
2. Download the repository.
3. Run:

```bash
python ai_study_assistant.py
```

## Example

Input:

```
Machine Learning
```

Output includes:

- Simple Explanation
- Key Points
- Study Tip
- Interview Questions
- Revision Notes
